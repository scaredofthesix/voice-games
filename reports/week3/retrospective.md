# Sprint 1 Retrospective (Team 40)

Public, sanitized retrospective for Sprint 1 (15-21 June 2026).

## What went well

1. We delivered all five planned MVP v1 stories and the customer accepted the increment.
2. We closed every issue the customer raised at the previous review (bubble speed, recognition
   stability, placeholder removal).
3. The team workflow held up: issue-linked branches, pull requests, a required teammate review,
   protected `main`, a changelog, and a first SemVer release (v0.1.0).

## What did not go well

1. The backlog trailed the discussion - built-in categories and phrases had been talked about
   but had no user stories until this review.
2. Estimation and acceptance criteria were added late (just before the review) rather than when
   the stories were written.
3. We have no automated deploy yet; the public GitHub Pages site is rebuilt and republished by
   hand.

## Action points

1. Turn every discussed idea into an issue the same day, with MoSCoW, MVP label, AC, and points.
2. Stand up the GitHub Project board (Backlog + Sprint views) and add a CI deploy workflow for
   GitHub Pages once branch-protection-compatible.
