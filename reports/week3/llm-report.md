# LLM Usage Report - Week 3 (Team 40)

This report describes how AI/LLM tools were used during Assignment 3.

## Tools used

- **Claude Code (Anthropic)** - used to help the team organize the Scrum process and polish
  deliverables, not to replace the team's product decisions.

## How it was used

- **Backlog grooming:** helped migrate and refine the user stories into GitHub Issues, keep
  stable IDs and MoSCoW priorities consistent, draft acceptance criteria, and apply the wording
  and scope changes the customer requested at the Sprint 1 review.
- **Estimation support:** helped apply a consistent Fibonacci story-point scale across the
  backlog and compute the sprint and backlog totals.
- **Reporting:** helped draft and format the Week 3 reports (customer review summary,
  reflection, retrospective, this report) and clean the meeting transcript for readability and
  PII removal while keeping the real meaning.
- **Workflow and release:** helped draft pull-request descriptions, the Definition of Done, the
  roadmap, the changelog entries, and the v0.1.0 release notes.

## Human oversight

- All AI-assisted content is reviewed, edited, and approved by the team before submission.
- Product decisions, estimates, and customer approvals are owned by the team and the customer,
  not the LLM.
- The transcript reflects the real meeting; the LLM only cleaned, sanitized, and reformatted it
  and did not invent statements or approvals.
