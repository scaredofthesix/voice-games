# MVP v2 Game Ideas (for customer comment)

The customer asked us to grow the game set (about four more games for MVP v2) and to collect
the ideas in a shared document for them to comment on before we build. This file is the
working list; it is mirrored into a shared Google Doc for customer comments. Tracked by
issue [#54](https://github.com/scaredofthesix/voice-games/issues/54).

## 1. Boss fight (proposed in the review)

A prince fights monsters. Each correctly pronounced word removes 1 HP from the boss
(for example, a boss with 8 HP needs 8 correct words). If the child does not pronounce the
word within about 10 seconds, the boss deals 1 damage; the child starts with 3 HP. Can scale
to several monsters - sequential is preferred, four words each - and the four words can form
a phrase, tying into the phrase mode (US-20).
